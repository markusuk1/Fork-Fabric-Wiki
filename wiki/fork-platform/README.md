# Complete Fork platform wiki

This directory is an additive mirror of the Fork repository's complete `wiki/`
knowledge base. Start with the [Fork wiki index](index.md); its append-only
[ingest log](log.md) records the knowledge history.

## Publication boundary

- The surrounding repository's GAME-OPENMW wiki is preserved unchanged.
- This subtree contains all 46 files from the Fork wiki at publication source
  `3ebb4d233` on 2026-08-14, plus this publication-boundary README. That source
  records the complete native Worldline Engine, final CHML `0/0/0/0`
  acceptance, and exact production build-39 release.
- The mirror intentionally contains documentation only: no credentials,
  generated databases, build products, implementation source, or private raw
  evidence is published.
- Some provenance links point back to private repository-relative evidence and
  may not resolve publicly. The article text still states the relevant source,
  build, audit and shipment boundary so an external model can distinguish
  shipped truth from proposals and internal implementation checkpoints.

The Fork wiki remains authoritative for Fork platform knowledge; the adjacent
GAME-OPENMW articles describe how that platform is consumed by the living-world
project.
