# Fork Fabric + OpenMW Living-World Wiki

This repository is the public knowledge base for the GAME-OPENMW research and
development project combining a Fork-based durable cognition fabric with
OpenMW's game simulation and presentation layer.

The current documented production baseline is `game-openmw-npc-v203`. Start
with the [wiki index](wiki/index.md). Useful entry points are:

## Repository scope

This repository mirrors the maintained wiki from the private implementation
repository. It intentionally excludes raw internal evidence, game assets,
credentials, local runtime state, generated databases, evidence media, build
products and implementation source. Raw provenance links and implementation
filenames document the grounded source boundary but may not resolve publicly.

Capability documents distinguish released/configured behaviour, historical
qualification revisions, explicit unaccepted expansions and separate future
programmes. Older database versions remain in the text when they identify the
exact evidence boundary for a completed task; they are not the current playable
target unless an article explicitly says so.

OpenMW and Morrowind are separate third-party projects and are not distributed
by this repository. Morrowind assets remain subject to their owners' rights and
the user's game licence.
