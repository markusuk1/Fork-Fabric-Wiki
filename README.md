# Fork Fabric + OpenMW Living-World Wiki

This repository is the public knowledge base for a research and development
project combining a Fork-based durable cognition fabric with OpenMW's game
simulation and presentation layer.

## Repository scope

This repository publishes the maintained wiki. It intentionally excludes raw
internal evidence, game assets, credentials, local runtime state, generated
databases, build products, and the private implementation repository.
References to implementation filenames document the tested system but may not
resolve to public source files.

Capability documents distinguish between released/configured behavior,
prototype evidence, and planned work. Source labels retain the provenance of
the internal research and verification records from which the wiki is compiled.

OpenMW and Morrowind are separate third-party projects and are not distributed
by this repository. Morrowind assets remain subject to their owners' rights and
the user's game licence.
